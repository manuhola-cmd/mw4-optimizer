Your PC

How do I check my RAM speed?
  1. Current speed: press Ctrl+Shift+Esc to open Task Manager → Performance tab → Memory. At the bottom it shows Speed (e.g. 4800 MT/s). Enter that number in the field above.
  2. Open PowerShell: click the Start button (the Windows logo), type PowerShell and press Enter. A blue or black window opens.
  3. Copy this command with the button, paste it into PowerShell with Ctrl+V (or right-click) and press Enter: 
    Get-CimInstance Win32_PhysicalMemory | Select-Object Manufacturer, PartNumber

Your monitor

How do I know if my monitor has G-Sync / FreeSync?
  1. Check your GPU software:
    NVIDIA: right-click the desktop → NVIDIA Control Panel → in the left menu under Display, look for Set up G-SYNC. If it's there, your monitor supports it.
    AMD: open AMD Software: Adrenalin → Gaming → Display. If you see AMD FreeSync, your monitor supports it.
  2. Check the monitor's own menu: use the buttons on the monitor and look for FreeSync, Adaptive-Sync, G-Sync or VRR. Turn it On. Many monitors ship with it off, and then step 1 won't show the option.
  3. Still not sure? Find your monitor's model on the sticker on the back, or in Windows: Settings → System → Display → Advanced display. Search the model on Google with "FreeSync" or "G-Sync".
  4. Use a DisplayPort cable if you can. With NVIDIA cards, many monitors only enable G-Sync/FreeSync over DisplayPort, not HDMI.

If you found any of these, check the box above. If not, leave it unchecked.
